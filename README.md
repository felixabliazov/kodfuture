# Bank Account System - Банковская система управления счетами 🏦

**Автор:** Алексей Смирнов

## 📝 Описание программы

Bank Account System - это консольное приложение для управления банковскими счетами, реализованное с использованием архитектурного шаблона MVC (Model-View-Controller). Программа позволяет создавать различные типы банковских счетов, выполнять финансовые операции и отслеживать историю транзакций.

### Основные возможности:

- ✅ **Различные типы счетов:**
  - Расчетный счет (с возможностью овердрафта)
  - Сберегательный счет (с начислением процентов)
  - Кредитный счет (с кредитным лимитом)

- ✅ **Финансовые операции:**
  - Пополнение счета
  - Снятие средств
  - Перевод между счетами
  - Начисление процентов

- ✅ **Управление транзакциями:**
  - История всех операций (хранится в очереди)
  - Фильтрация по типу транзакции
  - Фильтрация по диапазону дат

- ✅ **Безопасность и контроль:**
  - Проверка достаточности средств
  - Валидация пользовательского ввода
  - Блокировка/разблокировка счетов
  - Защита от отрицательных сумм

- ✅ **Сохранение данных:**
  - Автоматическое сохранение в JSON
  - Загрузка данных при запуске
  - Полная сериализация объектов
